# PracaTak — шаблон сайта по трудоустройству

Чёрно-золотой премиум-лендинг в стиле логотипа **PracaTak**. Одностраничный сайт
без сборки — чистый HTML + CSS + JS. Открывается двойным кликом или на любом
статическом хостинге.

## Концепция

Главная задача — **вызвать доверие**, а уже потом показать вакансии:

1. **Hero** — личность рекрутёра, «10 лет · 12 000+ трудоустроенных», 2 CTA
2. **Полоса цифр** — 12 000 клиентов · 10 лет · 10 стран · 0 предоплат
3. **О рекрутёре** — личный блок доверия (не колл-центр, а человек с репутацией)
4. **Вакансии** — фильтр по 10 странам, демо-карточки (рандомные)
5. **Отзывы** — масонри-сетка отзывов
6. **Гарантии** — «как отличить нас от мошенников»
7. **Форма заявки** — имя / телефон / страна / способ связи
8. **Подвал** + плавающие кнопки мессенджеров

## Структура

```
pracatak/
├── index.html        # вся разметка
├── css/style.css     # дизайн-система (чёрный + золото)
└── js/app.js         # ⭐ данные + рендер (тут всё редактируется)
```

## Что заменить на реальное (всё в js/app.js, вверху файла)

- `SITE` — телефон, email, ссылки Telegram / WhatsApp / Viber
- `RECRUITER` — имя, должность, фото (`photo:`), цитата
- `COUNTRIES` — список стран
- `VACANCIES` — вакансии (сейчас демо/рандом)
- `REVIEWS` — отзывы
- `GUARANTEES` — блоки гарантий

Фото-заглушки сейчас с `placehold.co` — замените на реальные (положите в
`pracatak/images/` и укажите путь, напр. `images/recruiter.jpg`).

### Логотип

Сейчас лого собрано на CSS (монограмма **PT** + ✈ + надпись PracaTak). Когда
будет готов настоящий PNG/SVG — заменить блок `.logo` в `index.html` на `<img>`.

### Форма заявки

Сейчас форма показывает экран «Заявка принята» без отправки. Чтобы подключить
реально — в `js/app.js`, функция `initForm`, добавьте `fetch()` на ваш бэкенд /
Formspree / Telegram-бот (отмечено `TODO`).

## Локальный запуск

```bash
cd pracatak
python3 -m http.server 8000
# открыть http://localhost:8000
```
